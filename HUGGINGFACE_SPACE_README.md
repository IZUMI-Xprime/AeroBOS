# AeroBOS: Real-Time Software-Defined Optical Gas Imaging

This Hugging Face Space hosts the interactive portfolio and live browser-based demonstration for **Team AeroBOS** in the **OpenCV AI Competition 2026, powered by AWS**.

### Key Deliverables in this Space:
- **`index.html`**: Live interactive research paper and simulator featuring real-time Background-Oriented Schlieren (BOS), Poisson FFT gas reconstruction, false-positive rejection (steam vs methane), and emergency SCADA valve isolation.
- **`aerobos_plume_annotated.jpg`**: False-color optical Schlieren gas evidence snapshot with vector flow quiver and HUD.
- **`predicted_plume_hazard_15min.geojson`**: 15-minute ConvLSTM hazard footprint for evacuation routing.

### Quick Deployment to Hugging Face Spaces:
1. Create a new Space on [Hugging Face](https://huggingface.co/new-space).
2. Select **Static HTML** as the Space SDK.
3. Upload `index.html`, `aerobos_plume_annotated.jpg`, and `predicted_plume_hazard_15min.geojson`.
4. Your interactive portfolio goes live immediately!
