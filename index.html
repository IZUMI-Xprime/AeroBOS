1Optical Physics: Snell's Law Inversion & Gladstone-Dale

Background-Oriented Schlieren (BOS) relies on the physical principle that variations in gas concentration or temperature alter the local refractive index n of the optical medium. According to the Gladstone-Dale relation, the refractive index of a gas mixture is linearly proportional to its local mass density ρ:

n(x, y, z) - 1 = KGD · ρ(x, y, z)

where KGD is the Gladstone-Dale constant. For methane (CH4) at λ=550 nm, KCH4≈4.30×10-4 m3/kg, compared to ambient air Kair≈2.26×10-4 m3/kg. This refractive index contrast causes paraxial light rays traversing the disturbance to deflect:

ε(x, y) = 1/n0 ∫ZD - ΔZ/2ZD + ΔZ/2 ∇⊥ n(x, y, z) dz

Projected onto a camera sensor with focal length f, camera-to-gas distance ZD, camera-to-background distance ZB, and sensor pixel pitch ppix, the virtual displacement corresponds directly to the spatial gradient of the Optical Path Difference (OPD) field Φ(x,y):

d(x, y) = CBOS · ∇⊥ Φ(x, y),   where   CBOS = f · (ZB - ZD) / ppix · ZB · n0

2Reconstruction: 2D Poisson Inversion via Fourier Transforms

Measuring the 2D displacement vector field d=(u,v) provides the spatial gradient of the projected gas density. Taking the 2D divergence yields a classical Poisson equation:

∇ · d = ∂u/∂x + ∂v/∂y = CBOS · ∇2 Φ(x, y)

Direct spatial solving via finite element or iterative Gauss-Seidel relaxations requires thousands of iterations, making real-time 1080p execution impossible. AeroBOS diagonalizes the Laplacian operator in discrete frequency space using the Discrete Fourier Transform (O(NlogN)) via OpenCV 5's cv2.dft and cv2.idft:

L(u, v) = 2 · [ cos(2πu/W) - 1 ] + 2 · [ cos(2πv/H) - 1 ]
Φ̂(u, v) = L(u, v) · ℱ{∇ · d}(u, v) / CBOS · [ L(u, v)2 + λreg ],   with   Φ̂(0, 0) = 0

The Tikhonov regularizer λreg=10-4 suppresses low-frequency ambient sensor drift while preserving sharp turbulent shear boundaries.

The complete, typed, and production-ready Python codebase is structured as follows: 

# SchlierenRefractometer Core Engine
class SchlierenRefractometer:
    def __init__(self, config: Optional[RefractometerConfig] = None):
        self.config = config or RefractometerConfig()
        self._dis_flow = cv2.DISOpticalFlow.create(self.config.dis_preset)
        self._setup_temporal_bandpass()

    def solve_poisson_2d(self, divergence_field: np.ndarray) -> np.ndarray:
        # Fast 2D FFT Poisson Inversion
        opt_h = cv2.getOptimalDFTSize(h)
        opt_w = cv2.getOptimalDFTSize(w)
        scaled_div = divergence_field / self.config.geometry.bos_coupling_coefficient
        dft_div = cv2.dft(scaled_div, flags=cv2.DFT_COMPLEX_OUTPUT)
        dft_div[:, :, 0] *= self._laplacian_kernel_dft
        dft_div[:, :, 1] *= self._laplacian_kernel_dft
        return cv2.idft(dft_div, flags=cv2.DFT_SCALE | cv2.DFT_REAL_OUTPUT)
